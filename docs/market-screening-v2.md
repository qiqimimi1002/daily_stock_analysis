# A股全市场初筛 V2

## V2.1 范围

V2.1 在现有“全市场行情过滤 → 历史行情核验 → Daily Stock 深度分析”
链路中增加透明评分，不替换主分析流程。

当前评分组件：

| 组件 | 满分 | 主要证据 |
|---|---:|---|
| 基本面 | 30 | 营收/净利润同比、ROE、毛利率、资产负债率、经营现金流 |
| 行业催化 | 20 | V2.1预留，不用模型猜测填分 |
| 资金面 | 20 | 成交额、换手率、量比/量能比、主力及多日资金流 |
| 技术面 | 20 | MA5/MA10/MA20、近5日涨跌、MA20偏离、当日位置 |
| 估值 | 10 | PE、PB |

行业催化的20分已作为未启用组件预留，将在后续版本接入结构化、可追溯
证据后计分。V2.1不会使用模型猜测填补缺失项。

## 评分与证据覆盖

报告同时展示：

- 综合评分：按有效证据计算，并对低覆盖率进行惩罚；
- 原始得分与有效满分；
- 证据覆盖率；
- 高/中/低置信度；
- 每个组件的得分、状态和证据；
- 证据缺口。

缺失数据不会按正面信号计分。“无法获取资金流”与“资金没有流出”
是不同结论。

当前公开接口主要提供最近报告期指标；最近3年净利润/毛利率趋势、连续
亏损年数和同行业估值分位在取得可核验证据前会列为缺口，不会假定通过。

## 风险门禁

基础过滤继续限定沪深A股主板，并排除创业板、科创板、北交所、ST、
退市整理和新上市简称；默认当日成交额与近20日平均成交额门槛均为2亿元。
若历史接口未返回成交额，报告会明确列为证据缺口，不会把它表述为已核验。

V2.1可核实的硬风险包括：

- 已核实连续亏损；
- 最新已核实归母净利润为负；
- 已核实重大风险公告或监管处罚；
- 已核实异常波动标记。

公开结构化数据不足时，报告会把公告、监管和财务风险列为证据缺口，
继续交由前三只候选的 Daily Stock 深度分析复核，不会写成“无风险”。

## 市场环境

市场环境分数使用全市场涨跌幅快照计算上涨家数占比、涨跌幅中位数、
涨停和跌停数量，并给出“积极观察 / 中性观察 / 偏谨慎”的策略。
该分数只影响观察优先级，不构成买卖建议。评分低于40分时观察名单
自动缩减到最多3只，40—55分时最多4只，其余环境最多5只。

## 运行参数

```bash
python scripts/run_market_screener.py \
  --top-n 5 \
  --analysis-limit 3 \
  --preselect-limit 60 \
  --enrichment-limit 8 \
  --evidence-workers 2 \
  --evidence-budget-seconds 12 \
  --min-amount-yuan 200000000
```

GitHub Actions 可通过同名的 `SCREEN_*` Repository variables 覆盖默认值。
